JSON doesn't mess around!

I searched the browser for dog API. The request was input into the browser and I got a response back with raw JSON. I was able to make it Pretty Print by clicking Prettier in the response page. What I got back was JSON that resembles an object only the code was not active. JSON requires double quotes on field names and is basically just an image of actual code or an object. Any small mis-step in JSON will not be JSON at all.
